A one-line resignation letter for make.fun's "The One-Line Exit" bounty: the funniest single-line resignation letter wins. This program writes one 138-character resignation letter — from the office's unofficial printer technician — to `/output/entry.txt`.

> Please accept my resignation: after three years of fixing the office printer, I realised I was never in IT — I was in a hostage situation.

The entry is deterministic, uses only the Node.js standard library, and needs no network access. It validates the line against the competition gate (1–140 characters, exactly one line) before writing it.

## Run it

```sh
node main.ts
```
